# Smart Tenant Management System — Frontend

## Run it
1. Extract this folder if it came as a ZIP.
2. In VS Code, open the `frontend` folder.
3. Open `index.html` in your browser. If you have the VS Code Live Server extension, right-click `index.html` and choose **Open with Live Server**.
4. No npm install or backend server is required for this demo.

## Files
- `index.html`: page structure
- `style.css`: dark charcoal and blue-accent design, responsive layout
- `script.js`: demo tenant data, browser localStorage, search, add/edit/delete, and payment status controls

## Important
This is a frontend demo. Data is stored only in the current browser using localStorage. It is not connected to Spring Boot or PostgreSQL yet. Use fictional tenant details while testing.
